# Chore description body (Kanboard task description)

This is the Markdown that goes in the task's **description**. Type, priority,
status, and created-date are NOT written here — they live in native Kanboard
fields (a `type` tag, the priority field, the column, the creation date). Only
author the body below.

## Summary

_One sentence: what's wrong, or what small change is wanted._

## Details

_Where it shows up; repro steps for a bug; or the specifics of the change.
Keep it brief — just enough for future-you to pick it up cold._

## Proposed Fix / Notes

_Optional: a hunch at the fix, the file/area likely involved, or a constraint.
Delete this section if there is nothing to add._
