captured as a stub. The task **title** is the feature name and its **column**
(Backlog) marks it as an unrefined stub — so don't repeat title/status/date here.
Author only the body below.

## Summary

_One sentence describing what this is._

## Problem / Opportunity

_What problem does this solve, or what opportunity does it unlock? Who is affected?_

## Success Looks Like

_Rough outcome criteria — what would "done" look like from a user or system perspective?_

## Notes & Open Questions

_Anything worth capturing early: constraints, unknowns, dependencies on other
stubs/PRDs (link by title or task id), rough technical hunches._
